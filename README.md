# STC8H8K64U 外设自检程序（RTX51 Tiny）

基于 STC8H8K64U 开发板的板级外设自检 / 演示程序：开机后通过按键在中文菜单中切换自检项目，当前选中项对应的外设执行演示动作，并在 OLED 上显示名称与实时数据。

## 工程与运行环境

| 项目 | 说明 |
| --- | --- |
| 工程 | Keil µVision（MCS-51 / C51 工具链），工程文件 `Project/STC8H8K64U.uvproj` |
| 主控芯片 | STC8H8K64U（STC 1T 8051 内核，64 KB Flash，8 KB XRAM） |
| 系统时钟 | 24 MHz（`MAIN_Fosc`） |
| 开发语言 | C51 + Ax51 汇编，Large 存储模式，编译输出 HEX，使用 STC-ISP 烧录 |
| 操作系统 | RTX-51 Tiny V2.02（`RTX51TNY.LIB` + `Conf_tny.A51`） |

## 操作系统与调度

RTX-51 Tiny 以 Timer0 作为系统节拍，配置为时间片轮转（`TIMESHARING = 5`）。任务 0 完成 `sys_init()` 后创建常驻任务并自我删除；任务间通过 `os_wait1(K_SIG)` / `os_send_signal()` 进行事件同步，通过 `os_wait2(K_TMO, n)` 实现周期性采样与刷新。每个自检项目对应一个独立任务，按需 `os_create_task()` / `os_delete_task()` 动态启停。

## 外设清单

| 外设 | 接口 / 引脚 | 用途 |
| --- | --- | --- |
| SPI OLED 128×64（带 GB2312 字库） | 软件模拟 SPI，P5.0 / P1.3 / P1.6 / P4.7 等 | 显示 4 行中文自检菜单 |
| I2C OLED 128×64 | P3.2 / P3.3 | 显示当前项目与实时数据 |
| 8 位 LED | GPIO（P2 / P1 / P4.5 使能） | 流水灯 |
| 4 个独立按键 | P5.1 ~ P5.4 | 菜单上翻 / 下翻 |
| 4×4 矩阵键盘 | 行 P3.4/P3.5/P4.0/P4.1，列 P0.3/P0.6/P0.7/P1.7 | 按键发声（电子琴） |
| 8 位数码管 | 74HC595 级联，P4.2 / P4.3 / P4.4 | 动态扫描显示 |
| 蜂鸣器 | PWMB 通道 5 / P0.0 | PWM 频率输出不同音阶 |
| 直流电机 | PWMB 通道 6 / P0.1 | PWM 调速 |
| NTC 热敏电阻 | ADC CH12 / P0.4 | 测温 |
| 电位器 | ADC CH13 | 调节电机 PWM 占空比 |
| DHT11 | 单总线 P4.6 | 温湿度采集 |
| RTC（PCF8563 兼容） | 硬件 I2C，地址 0xA2 | 时钟读写、串口对时 |
| UART1 | P3.0 / P3.1，115200 | `printf` 调试输出、RTC 串口对时 |

## 功能与实现

菜单共 7 项：LED 流水灯、NTC 温度、电机 PWM、RTC 时钟、数码管、DHT11 温湿度、蜂鸣器 + 矩阵键盘。

- **菜单与显示**：SPI OLED 任务以循环取模方式显示 4 行菜单，首行以 `>` 标记选中项；I2C OLED 任务按全局索引 `g_cur_pos` 调用对应的 `XXX_Display()` 显示数据；两个显示任务均在信号到达后才刷新。
- **任务切换**：按键任务周期性扫描独立按键，切换时先删除旧任务并关闭对应外设（关 LED、关 PWM、关定时器等），再创建新任务并初始化外设，最后发送信号通知刷新。
- **各项目任务**：LED 按节拍逐点点亮；NTC 用 ADC 采样后查表换算温度；电机由 ADC 电压换算占空比并更新 PWM6；数码管由 Timer2 产生 1 kHz 中断、经 74HC595 动态扫描；DHT11 按单总线时序读取；蜂鸣器项目扫描矩阵键盘并用 PWM5 输出音阶；RTC 通过 I2C 读写 BCD 时间寄存器并支持串口对时。
- **代码分层**：`Library/`（STC 官方外设库：GPIO/UART/I2C/SPI/ADC/PWM/Timer/RTC/NVIC/EXTI）、`Hardware/`（板级驱动）、`APP/`（自检任务）、`User/`（main 与初始化）、`System/`（RTX51 配置与延时）、`Start/`（STC8H 头文件与中断向量重定向）。
